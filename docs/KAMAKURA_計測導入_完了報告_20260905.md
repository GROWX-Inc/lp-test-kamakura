## 4. 計測できないもの

- **ebica（外部予約システム）での予約完了** — 計測できるのは予約ボタンのクリック（サイト離脱）までです。予約完了は ebica のドメイン上で発生するため、本サイトの計測範囲外です。
- **実来店** — 計測できません。
- 上記2点により、「LP経由の予約数」「来店数」は GA4 単体では把握できません。把握するには ebica 側のレポートとの突き合わせが必要です。

### 補足事項

- **API 無料枠は億万鳥者と共用**です（`COUNTER_DIR` 同一）。日次25回・月次775回を2ブランドで分け合うため、口コミのタップが増えると早期に link 表示へフォールバックします。分離する場合は `COUNTER_DIR` を別パスにするだけで対応できます。
- `scroll_reach` の到達点のうち `reserve`（`.resv-btnwrap`）は初期状態で非表示のため、通常のスクロールでは発火しません（画面切替後に発火する設計）。
- LP に `tel:` リンクは存在しないため、電話タップの計測はありません。
- config の `review_link_ids`（`hdCta` / `dwGr`）に該当する要素が `index.html` に無いため、口コミ導線のクリック計測は既存 gMeas v1 側の実装に依存します。
